# 캡컷 자동 편집기

여러 영상을 넣으면 무음을 잘라내고, 음성을 받아써 자막을 만들고,
캡컷 드래프트로 구워 주는 로컬 도구다. 브라우저로 조작하지만 서버는 내 PC 에서만 돈다.

## 설치

1. 파이썬 3.9 이상 설치 (윈도우는 설치할 때 **Add Python to PATH** 체크)
2. ffmpeg 설치 후 PATH 등록 — 오디오 분석에 필요
3. `캡컷 자동 편집기 실행.bat` 더블클릭 (처음 한 번은 패키지를 자동으로 깐다)

직접 실행하려면:

```
pip install -r requirements.txt
python run.py
```

## 진행 순서

| 단계 | 하는 일 |
|---|---|
| 1. 설정 확인 | 캡컷 폴더·ffmpeg·whisper 준비 상태를 본다 |
| 2. 원본 영상 | 영상을 골라 순서대로 이어 붙인다 |
| 3. 캘리브레이션 | 내가 꾸며 둔 드래프트에서 자막 스타일을 읽어 온다 |
| 4. 분석·전사 | 무음을 찾아 컷 후보를 만들고 음성을 받아쓴다 |
| 5. 대본·자막 | 대본 표기 + 전사 타이밍으로 자막을 만든다 |
| 6. 컷 편집 | 살릴 구간을 체크로 고르고 확정한다 |
| 7. 드래프트 | 캡컷 드래프트를 생성한다 |
| 8. 마케팅 | 제목·설명·해시태그용 프롬프트를 뽑는다 |

앞 단계를 마쳐야 다음 단계가 열린다. 앞 단계를 다시 하면 뒤 단계는 자동으로 풀린다.

## 알아 둘 것

- **드래프트는 항상 백업하고 덮어쓴다.** 백업은 `backups/` 에 시간 도장이 찍혀 쌓인다.
- **전사는 청크 단위로 저장된다.** 중간에 껐다 켜도 끝난 청크는 다시 돌리지 않는다.
- **캡컷이 켜져 있으면** 새 드래프트가 목록에 안 보일 수 있다. 껐다 켜면 나온다.
- 로그는 `logs/YYYY-MM-DD.log` 에 날짜별로 쌓인다.

## 폴더

```
assets/sfx/   효과음을 넣어 두는 곳
assets/bg/    배경음을 넣어 두는 곳
data/         설정·용어 사전·캘리브레이션 프로파일·세션
backups/      드래프트 백업
logs/         날짜별 로그
```
