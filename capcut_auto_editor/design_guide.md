# UI 디자인 토큰

> **상태: 자리표시자.** 실제 디자인 가이드가 들어오면 이 문서와
> `app/static/styles.css` 맨 위 `:root` 블록만 교체하면 된다.
> 나머지 CSS 는 전부 이 토큰만 참조하므로 다른 파일은 건드릴 필요가 없다.

## 색

| 토큰 | 현재 값 | 쓰임 |
|---|---|---|
| `--bg` | `#f6f7f9` | 페이지 바탕 |
| `--surface` | `#ffffff` | 카드·입력창 바탕 |
| `--surface-2` | `#f0f2f5` | 보조 바탕, 호버 |
| `--border` | `#dfe3e8` | 테두리, 구분선 |
| `--text` | `#1c1f23` | 본문 |
| `--text-dim` | `#666e78` | 설명, 보조 정보 |
| `--accent` | `#2f6df6` | 주 버튼, 활성 단계 |
| `--accent-weak` | `#e8efff` | 활성 배경, 포커스 링 |
| `--ok` | `#17a673` | 완료 |
| `--warn` | `#d98324` | 주의, 힌트 |
| `--error` | `#d94040` | 실패 |

## 형태

| 토큰 | 현재 값 |
|---|---|
| `--radius` | `10px` (카드), 버튼·입력은 `8px` |
| `--gap` | `16px` |
| `--font` | Pretendard → 맑은 고딕 → 시스템 폰트 |

## 레이아웃

- 3단: 단계 목록(200px) · 본문(가변) · 작업/로그(320px)
- 1100px 아래에서는 1단으로 접힘
- 헤더는 상단 고정, 로그 패널은 `top: 68px` 로 따라 붙음

## 손댈 때 주의

- 색은 반드시 토큰으로. 하드코딩된 색은 로그 패널 배경(`#1e2126` 계열)뿐이고,
  이건 어두운 콘솔 느낌을 의도한 것이라 토큰과 분리돼 있다.
- 다크 모드를 넣는다면 `:root` 아래에
  `@media (prefers-color-scheme: dark)` 로 같은 토큰만 다시 정의하면 된다.
