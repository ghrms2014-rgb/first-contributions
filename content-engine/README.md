# content-engine — 주말에 굴리는 뉴스레터 자동화

수집 → 선별 → 초안까지 **자동**, 마지막 코멘트만 **사람**이 쓰는 구조입니다.
파이썬 표준 라이브러리만 쓰기 때문에 설치할 것이 없고, 운영 비용은 **0원**입니다.

| 항목 | 도구 | 비용 |
| --- | --- | --- |
| 뉴스 수집 | RSS (구글뉴스 등) | 0원 |
| 매일 자동 실행 | GitHub Actions | 0원 (공개 저장소 무제한) |
| 글 저장 | 이 저장소 | 0원 |
| 웹 발행 | GitHub Pages | 0원 |
| 이메일 발송 | Substack / Beehiiv 무료 플랜 | 0원 |

---

## 먼저 알아야 할 것 (중요)

**AI가 전부 써서 그대로 발행하는 구조는 돈이 안 됩니다.** 검색엔진은 원본 없는
요약 묶음을 거의 노출시키지 않고, 애드센스도 그런 사이트를 잘 승인하지 않습니다.

그래서 이 도구는 글을 대신 써주지 않습니다. 대신 **가장 시간이 오래 걸리는
"뭘 쓸지 고르는 일"을 없애줍니다.** 매일 40~60분 걸리던 일이 15분이 됩니다.
`왜 중요한가` 한 줄만은 반드시 본인이 씁니다 — 그게 이 뉴스레터의 실제 상품입니다.

### 수익 현실 (부풀리지 않은 숫자)

| 시점 | 상태 | 예상 수익 |
| --- | --- | --- |
| 1~2개월 | 구독자 0~100명, 발행 습관 만들기 | A$0 |
| 3~6개월 | 구독자 300~1,000명 | 월 A$0~100 (제휴 링크) |
| 6~12개월 | 구독자 1,000명 이상 | 월 A$100~500 (제휴 + 유료 구독 + 스폰서) |

영어권 독자를 상대하면 같은 구독자 수에서도 광고·제휴 단가가 한국어 시장보다
대체로 높습니다. 시드니에 계신 건 이 점에서 유리한 조건입니다.

빠른 길이 아닙니다. 대신 **꾸준히 발행하는 것 말고 다른 변수가 없어서**,
주말만 쓸 수 있고 코딩을 모르는 상황에서 현실적으로 가능한 몇 안 되는 방식입니다.
3개월 안에 그만두면 A$0입니다. 이건 도구가 아니라 습관의 문제입니다.

## 1. 처음 한 번만 (약 20분)

### (1) 주제를 정하세요 — 가장 중요한 결정입니다

영어 / 호주 시장을 노린다면 **주제를 좁히는 게 전부**입니다. "AI 뉴스" 같은
넓은 주제는 이미 대형 매체가 다 잡고 있어서 이길 방법이 없습니다.

후보 3개를 바로 쓸 수 있게 프리셋으로 넣어두었습니다.

```bash
python3 content-engine/use_preset.py                    # 목록 보기
python3 content-engine/use_preset.py ai-small-business  # 적용
```

| 프리셋 | 독자 | 수익성 | 경쟁 | 이런 분에게 |
| --- | --- | --- | --- | --- |
| `ai-small-business` | 호주 소상공인·자영업자 | 높음 (SaaS 제휴 건당 A$50~200) | 보통 | 도구/기술에 관심 있으면 |
| `sydney-first-home` | 시드니 첫 주택 구매자 | 매우 높음 (금융 광고) | 심함 | 부동산·금리를 계속 보고 있다면 |
| `au-migration-jobs` | 비자·구직 준비생 | 보통 | 보통 | 본인 경험이 곧 콘텐츠가 되는 분야 |

**추천은 `ai-small-business` 입니다.** 금융(부동산)은 단가가 제일 높지만 대형
매체와 정면으로 붙어야 하고, 소상공인 대상 AI 도구는 아직 호주 현지 관점으로
정리해주는 곳이 드물어서 신규 진입자가 자리를 잡을 여지가 있습니다.

> **`au-migration-jobs` 선택 시 주의:** 호주에서 이민 관련 '조언'은 등록
> 이민대리인(MARA)만 할 수 있는 규제 영역입니다. 정책 변화를 **보도·요약**하고
> 공식 출처를 링크하는 건 문제가 없지만, 개별 독자에게 "당신은 이 비자를
> 신청하세요" 같은 맞춤 조언을 하면 선을 넘습니다. 매 호에 "This is news, not
> immigration advice" 문구를 넣고, 항상 Home Affairs 원문을 링크하세요.

세 개 다 돌려보고 초안 품질을 비교한 뒤 정해도 됩니다. `use_preset.py` 는
바꾸기 전 `config.json.backup` 을 남깁니다.

### (2) `config.json` 을 고치세요 — 코드는 건드릴 필요 없습니다

```json
"brand": {
  "title": "뉴스레터 이름",
  "tagline": "한 줄 소개",
  "author": "본인 이름"
}
```

소스를 바꾸려면 `sources` 의 `url` 을 바꿉니다. 구글뉴스는 검색어만 바꾸면 되므로
가장 쉽습니다 — 아래 주소에서 `검색어` 부분만 바꾸세요.

```
# 영어 / 호주
https://news.google.com/rss/search?q=검색어&hl=en-AU&gl=AU&ceid=AU:en

# 한국어
https://news.google.com/rss/search?q=검색어&hl=ko&gl=KR&ceid=KR:ko
```

`keywords` 는 점수 가중치입니다. 숫자가 클수록 위로 올라옵니다.
`blocklist` 에 넣은 단어가 들어간 글은 아예 제외됩니다.

### (3) 한 번 돌려보세요

```bash
python3 content-engine/run.py
```

`content-engine/drafts/오늘날짜.md` 파일이 생기면 성공입니다.

> 설정을 바꾼 뒤 문제가 있는지 확인하려면 `python3 content-engine/selftest.py` 를
> 실행하세요. 인터넷 없이도 도는 검사입니다.

### (3-2) 구독 신청 링크 연결 — 이거 안 하면 수익은 영원히 A$0입니다

읽을 사람을 모으지 못하면 제휴도 유료 구독도 성립하지 않습니다.
**Substack(또는 Beehiiv)에 무료 계정을 먼저 만들고**, 그 주소를
`config.json` 의 `brand.subscribe_url` 에 넣으세요.

```json
"brand": {
  "subscribe_url": "https://내이름.substack.com",
  "subscribe_heading": "Get three practical AI picks every Tuesday",
  "subscribe_blurb": "Free. Written for Australian small business owners, not engineers."
}
```

넣는 순간 모든 페이지 아래에 구독 버튼이 생깁니다. 비워두면 버튼이
아예 나오지 않고, 빌드할 때 경고가 뜹니다.

`brand.base_url` 에 GitHub Pages 주소를 넣으면 canonical 태그와 RSS의
절대 주소가 채워집니다. 링크드인·X에 공유했을 때 제목과 설명이
제대로 보이려면 이게 있어야 합니다.

### (4) 자동 실행 켜기

`.github/workflows/content-engine.yml` 이 이미 들어 있습니다. 저장소에 push하면
매일 시드니 아침(UTC 20:00 = AEST 06시 / AEDT 07시)에 알아서 돌고 초안을 커밋합니다.
Actions의 cron은 UTC 고정이라 서머타임에 따라 1시간 밀립니다. 신경 쓰이면
`.github/workflows/content-engine.yml` 의 `cron` 을 계절마다 바꾸세요.
저장소 **Settings → Actions → General → Workflow permissions** 에서
`Read and write permissions` 를 켜야 커밋이 됩니다.

### (5) 웹사이트 켜기

**Settings → Pages → Source 를 `GitHub Actions` 로** 바꾸세요.
(`Deploy from a branch` 는 루트나 `/docs` 만 고를 수 있는데 이 저장소의
`/docs` 는 이미 다른 용도로 차 있어서 쓸 수 없습니다.)

`.github/workflows/pages.yml` 이 `creator-hub` 와 `content-engine` 을 함께
빌드해 배포합니다. 허브가 루트, 글 목록이 `/brief/` 입니다.

## 2. 매일 (또는 매주) 하는 일 — 15분

1. `content-engine/drafts/` 에서 오늘 초안을 엽니다.
2. 5개 중 **정말 중요한 3개만 남기고 지웁니다.** 많이 넣을수록 안 읽힙니다.
3. 각 항목의 `왜 중요한가` 를 본인 문장으로 채웁니다. 이게 전부입니다.
4. 제목 후보 중 하나만 남깁니다.
5. 체크리스트를 확인한 뒤 파일을 `content-engine/posts/` 로 옮기고
   `status: draft` 를 `status: published` 로 바꿉니다.
6. 커밋하면 사이트에 올라갑니다. 같은 내용을 Substack에 붙여넣어 메일도 보냅니다.

## 3. 수익 붙이기 (구독자가 생긴 뒤에)

순서를 지키세요. 구독자 없이 광고부터 붙이면 둘 다 실패합니다.

1. **먼저 30편을 발행하세요.** 이 단계에서는 수익 0원이 정상입니다.
2. **제휴 링크** (구독자 300명~)
   - Amazon Associates **호주 프로그램** (amazon.com.au) — 한국의 쿠팡파트너스에 해당
   - SaaS 어필리에이트: Impact, PartnerStack, ShareASale — 소프트웨어 주제라면 단가가 훨씬 높습니다
   - 광고임을 본문 맨 위에 명확히 표기해야 합니다 (아래 4번 참고)
3. **유료 구독** (구독자 1,000명~) — Substack / Beehiiv 유료 플랜.
   정산은 Stripe로 이뤄지고 Stripe는 호주 계좌를 지원하므로 그대로 받으실 수 있습니다.
4. **스폰서** (구독자 2,000명~) — 이 단계부터 금액이 의미 있어집니다.

### 호주에서 돈을 받기 시작하면 (세무 — 반드시 확인하세요)

아래는 일반적인 내용이고 **세무 조언이 아닙니다.** 실제 신고는 ATO 안내나
회계사(registered tax agent)에게 확인하세요.

- **ABN**: 사업으로 볼 수 있는 활동이면 ABN(Australian Business Number)이 필요합니다.
  Australian Business Register에서 무료로 발급됩니다.
- **취미 vs 사업**: ATO는 '사업에 해당하는지'를 규모·반복성·이익 의도 등으로 판단합니다.
  취미 수준이면 신고 대상이 아닐 수 있지만, 꾸준히 수익이 나면 사업으로 봅니다.
- **GST**: 연 매출이 **AUD 75,000** 을 넘으면 GST 등록이 의무입니다.
  뉴스레터 초기에는 해당될 일이 거의 없습니다.
- **해외 소득**: 호주 세무 거주자는 전 세계 소득을 신고합니다.
  미국 회사(Substack, Amazon US 등)에서 받는 돈도 포함됩니다.
- 미국 플랫폼은 보통 **W-8BEN** 양식을 요구합니다. 호주는 미국과 조세조약이 있어
  이 양식을 제출하면 원천징수율이 낮아집니다. 안 내면 30%가 떼입니다.

## 4. 하지 말아야 할 것

- 기사 본문을 그대로 복사 → 저작권 침해입니다. 요약과 링크까지만 쓰세요.
- 하루에 여러 편 발행 → 구독 해지의 1순위 이유입니다.
- 주제 바꾸기 → 3개월은 같은 주제로 가세요.
- 제휴 링크 표기 누락 → 호주에서는 **호주소비자법(ACL)** 상 오인유발 행위가 될 수 있고,
  ACCC가 인플루언서 광고 미표기를 실제로 단속해 왔습니다. AANA 광고윤리강령도
  '광고임을 명확히 알 수 있어야 한다'고 정하고 있습니다.
  `#ad`, `Sponsored`, `제휴 링크 포함` 같은 표기를 글 맨 위에 두세요.
  링크에 `rel="sponsored"` 를 붙이는 것도 검색엔진 쪽에서 권장됩니다.

## 파일 구조

```
content-engine/
├─ config.json      ← 여기만 고치면 됩니다
├─ presets/         주제 프리셋 3종
├─ use_preset.py    프리셋 적용 (백업 자동 생성)
├─ collect.py       RSS 수집 (중복 제거, 14일치 보관)
├─ draft.py         점수 매기고 초안 생성
├─ build_site.py    posts/*.md → site/*.html
├─ run.py           위 3개를 순서대로 실행
├─ selftest.py      인터넷 없이 도는 자체 점검
├─ data/            수집 원본 (자동 관리)
├─ drafts/          자동 생성된 초안  ← 여기를 다듬어서
└─ posts/           발행한 글         ← 여기로 옮깁니다
```
