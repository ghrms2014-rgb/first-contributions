# 먼저 찍을 릴스 3개

목표는 조회수가 아닙니다. **도달 1,000명당 팔로우 10 이상**입니다.
지금 0.33이니, 조회 3,000짜리 영상에서 팔로우 30명이 나오면 성공입니다.

세 개 다 **호주 건설 취업을 검색하는 사람**만 노립니다.
호기심으로 퍼지지 않습니다. 조회수는 낮을 겁니다. 그게 정상입니다.

> 숫자는 제가 지어내지 않았습니다. `[본인 숫자]` 로 표시된 곳은
> 실제로 받으신 금액·기간을 넣으세요. 정확한 숫자가 이 콘텐츠의 전부입니다.

---

## 1. White Card, 실제로 얼마 들고 며칠 걸리나

**왜 이걸 먼저 찍나:** 호주 건설 취업을 알아보는 사람이 가장 먼저 검색하는
단어입니다. 검색 의도가 명확한 만큼 저장률이 높고, 저장은 팔로우로 이어집니다.

**첫 3초 (여기서 다 결정됩니다)**

> 화면: White Card 실물을 손에 들고 클로즈업
> 자막: **"White Card 없이 호주 현장 못 들어갑니다"**
> 말: "이거 없으면 현장 입구에서 돌려보냅니다."

**구성 (25~35초)**

| 초 | 내용 | 화면 |
| --- | --- | --- |
| 0-3 | 위 훅 | 카드 클로즈업 |
| 3-8 | "온라인으로 하루면 됩니다. 비용은 `[본인 숫자]`" | 자막으로 금액 크게 |
| 8-15 | "근데 이것만 있으면 되는 줄 아는데, 아닙니다" | 본인 얼굴 |
| 15-25 | 추가로 필요했던 티켓 `[본인 경험]` 나열 | 자막 리스트 |
| 25-32 | "저는 이거 몰라서 `[본인 경험]` 했습니다" | 얼굴 |
| 32-35 | CTA (아래) | — |

**CTA — 이 부분이 팔로우를 만듭니다**

"다음 편에 **첫 현장 출근날 실제로 뭘 물어보는지** 올립니다."

돌아올 이유를 주는 겁니다. "팔로우 해주세요"보다 훨씬 잘 먹힙니다.

**캡션**

```
White Card만 있으면 되는 줄 알았습니다.

저는 [본인 경험] 때문에 첫 현장에서 [본인 경험] 했습니다.
지금 준비하시는 분들은 이거 미리 아세요.

프로필 링크에 제가 실제로 거친 순서 정리해뒀습니다.

#호주취업 #호주건설 #화이트카드 #호주워홀 #시드니 #호주이민 #건설현장
```

## 2. 삽질에서 안전관리자까지, 실제로 걸린 시간

**왜 이걸 찍나:** 이 계정이 왜 존재하는지를 설명하는 영상입니다.
신규 유입에게 "이 사람을 왜 팔로우해야 하는지"를 알려줍니다.
552개 중에 이런 영상이 상단에 고정돼 있어야 합니다.

**첫 3초**

> 화면: 삽질하던 시절 사진/영상 (있으면 반드시 사용)
> 자막: **"3년 전 저는 이거 하고 있었습니다"**
> 말: 없음. 화면만.

**구성 (35~45초)**

| 초 | 내용 | 화면 |
| --- | --- | --- |
| 0-4 | 과거 사진 + 자막 | 옛날 자료 |
| 4-8 | 컷 전환 → 지금 안전관리자 복장 | 현재 현장 |
| 8-20 | 순서를 담담하게: 라보러 → `[본인 경로]` → 지금 | 자막 타임라인 |
| 20-32 | "제일 오래 걸린 건 `[본인 경험]` 이었습니다" | 얼굴, 진솔하게 |
| 32-40 | "영어 못해도 됩니다. 근데 `[본인 생각]` 은 필요합니다" | 얼굴 |
| 40-45 | CTA | — |

**CTA**

"어디서 막히셨는지 댓글 남겨주시면, 제가 겪은 대로 답 드리겠습니다."

댓글을 부르는 CTA입니다. 댓글은 도달을 늘리고, 다음 소재도 됩니다.

**캡션**

```
삽질부터 시작했습니다.

누가 알려주는 사람이 없어서 [본인 경험] 하면서 배웠습니다.
지금 시작하시는 분들은 저처럼 돌아가지 마세요.

어디서 막히셨나요? 댓글 주시면 답 드립니다.

#호주취업 #호주건설 #시드니 #안전관리자 #호주이민 #호주생활 #커리어
```

## 3. 현장에서 즉시 쫓겨나는 행동

**왜 이걸 찍나:** 본인 직업이 Safety Coordinator입니다. 이건 **본인만
권위 있게 말할 수 있는 주제**입니다. 경고 형식이라 저장률이 높습니다.

**첫 3초**

> 화면: 현장 배경, 본인 안전 복장
> 자막: **"이거 하면 그날로 집에 갑니다"**
> 말: "제가 실제로 돌려보낸 사람들입니다."

**구성 (30~40초)**

| 초 | 내용 | 화면 |
| --- | --- | --- |
| 0-3 | 위 훅 | 현장 |
| 3-12 | 1번 `[본인 경험]` — 실제 목격한 것 | 자막 번호 크게 |
| 12-21 | 2번 `[본인 경험]` | 자막 |
| 21-30 | 3번 `[본인 경험]` — 가장 흔한 것을 마지막에 | 자막 |
| 30-36 | "한국에서는 넘어가는데 여기선 안 됩니다" | 얼굴 |
| 36-40 | CTA | — |

**CTA**

"저장해두세요. 첫 출근 전날 다시 보시면 됩니다."

저장을 직접 요청합니다. 저장률이 지금 0.15인데 이 한 줄로 올라갑니다.

**캡션**

```
Safety Coordinator로 일하면서 실제로 돌려보낸 경우들입니다.

한국 현장이면 그냥 넘어갈 일인데, 여기선 그날로 끝납니다.
악의가 있어서가 아니라 몰라서 그러는 경우가 대부분입니다.

첫 출근 앞두신 분들 저장해두세요.

#호주건설 #안전관리 #호주취업 #시드니 #건설현장 #호주워홀 #safetyfirst
```

## 찍고 나서 반드시 할 것

올린 지 **48시간 뒤** 인사이트를 열어 기록하세요.

```bash
python3 content-engine/ideas.py --log "White Card 실제 비용" \
  --angle checklist --reach <조회한 사람> --follows <팔로우> --saves <저장>
```

3개만 쌓이면 어느 앵글이 본인 계정에서 통하는지 숫자로 나옵니다.
그때부터는 감이 아니라 데이터로 정합니다.

## 예상되는 것 — 미리 알고 계세요

**조회수는 "호주숲"보다 훨씬 낮을 겁니다.** 3천에서 1만 사이일 가능성이 높습니다.
호기심으로 퍼지는 주제가 아니기 때문입니다.

그런데 **팔로우는 더 많이 나올 겁니다.** 그게 목표입니다.

조회수가 낮다고 실망해서 다시 호기심 콘텐츠로 돌아가면, 지난 552개와
같은 결과가 나옵니다. 숫자는 팔로우/1k만 보세요.
