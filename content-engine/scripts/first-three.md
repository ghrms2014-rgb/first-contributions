# 먼저 찍을 릴스 3개 (회사 제약 반영판)

## 촬영 제약 — 전부 여기에 맞춰 썼습니다

회사로부터 **로고·현장 노출 불가** 답변을 받은 상태입니다.

**절대 안 되는 것**

- 회사 로고 (헬멧, 조끼, 차량, 서류, 명함, 출입증)
- 현장 영상·사진 (배경에 스치는 것도 포함)
- 회사명·프로젝트명·고객사명 언급
- 동료 얼굴, 목소리, 알아볼 수 있는 특징
- **본인 회사에서 실제로 있었던 사고·징계 사례** — 이건 회사 문제를 넘어
  법적 위험이 됩니다. 산재는 조사 대상이고 관련자 정보는 민감정보입니다

**써도 되는 것**

- 본인 얼굴 (집, 차 안, 카페, 공원 — 사복)
- 본인 소유 장비 (로고 없거나 가린 것)
- 공개 자료 화면 녹화 (SafeWork NSW, White Card 신청 페이지, 정부 사이트)
- 종이·화이트보드에 손으로 쓰기
- 가린 서류 (급여명세서 금액만 보이게, 나머지 전부 가림)
- 본인 경험을 **일반화해서** 말하기 ("호주 현장에서는 보통…")

---

## 이 제약이 오히려 유리한 이유

현장 영상이 없어서 손해라고 느끼실 텐데, 데이터는 반대를 말합니다.

**"호주숲" 릴스는 볼거리가 강한 영상이었고, 전환이 0.33으로 최하위였습니다.**
풍경은 조회수를 만들지 전환을 만들지 않습니다. 정보를 찾아온 사람은
배경을 보러 온 게 아니라 **답을 들으러 온 것**입니다.

토킹헤드 + 자막은 정보 니치에서 전환이 가장 높은 포맷입니다.
제약 때문에 어쩔 수 없이 하는 게 아니라, **원래 이게 맞습니다.**

---

## 1. White Card, 실제로 얼마 들고 며칠 걸리나

**촬영 장소:** 집 책상 또는 카페. 현장 필요 없음.
**필요한 것:** 휴대폰, White Card 실물(회사 로고 없음), 노트북 화면

**첫 3초**

> 화면: 손에 White Card 클로즈업 (배경은 책상)
> 자막: **"이거 없으면 호주 현장 입구에서 돌려보냅니다"**
> 말: "그런데 이것만 있으면 되는 게 아닙니다."

**구성 (25~35초)**

| 초 | 내용 | 화면 |
| --- | --- | --- |
| 0-3 | 위 훅 | 카드 클로즈업 |
| 3-10 | "온라인 하루면 됩니다. 비용 `[본인 숫자]`" | **신청 사이트 화면 녹화** |
| 10-16 | "근데 이것만으로 일 못 합니다" | 정면 토킹헤드 |
| 16-26 | 추가로 필요했던 티켓 `[본인 경험]` | 자막 리스트 (화면 가득) |
| 26-32 | "저는 이거 몰라서 `[본인 경험]`" | 토킹헤드 |
| 32-35 | CTA | — |

**CTA:** "다음 편에 **첫 출근날 실제로 뭘 물어보는지** 올립니다."

**캡션**

```
White Card만 있으면 되는 줄 알았습니다.

저는 [본인 경험] 때문에 [본인 경험] 했습니다.
지금 준비하시는 분들은 미리 아세요.

프로필 링크에 제가 거친 순서 정리해뒀습니다.

#호주취업 #호주건설 #화이트카드 #호주워홀 #시드니 #호주이민
```

## 2. 삽질에서 안전관리자까지, 실제로 걸린 시간

**촬영 장소:** 집 또는 차 안. **과거 사진은 쓰지 마세요** — 배경에 현장이나
로고가 있을 가능성이 높습니다. 자막 타임라인으로 대체합니다.

**첫 3초**

> 화면: 정면 토킹헤드, 무표정하게
> 자막: **"3년 전 저는 영어도 못 했습니다"**
> 말: "지금은 안전관리자로 일합니다."

**구성 (35~45초)**

| 초 | 내용 | 화면 |
| --- | --- | --- |
| 0-5 | 위 훅 | 토킹헤드 |
| 5-20 | 순서를 자막 타임라인으로: 라보러 → `[본인 경로]` → 지금 | **자막이 주인공**, 얼굴은 작게 |
| 20-33 | "제일 오래 걸린 건 `[본인 경험]` 이었습니다" | 토킹헤드, 진솔하게 |
| 33-40 | "영어보다 `[본인 생각]` 이 더 중요했습니다" | 토킹헤드 |
| 40-45 | CTA | — |

**CTA:** "어디서 막히셨는지 댓글 주시면 제가 겪은 대로 답 드리겠습니다."

**캡션**

```
삽질부터 시작했습니다.

알려주는 사람이 없어서 [본인 경험] 하면서 배웠습니다.
지금 시작하시는 분들은 저처럼 돌아가지 마세요.

어디서 막히셨나요? 댓글 주시면 답 드립니다.

#호주취업 #호주건설 #시드니 #안전관리자 #호주이민 #호주생활
```

## 3. 호주 현장에서 즉시 돌려보내지는 행동

**촬영 장소:** **퇴근길 차 안(주차 상태)** 을 추천합니다. 현장이 안 나오면서도
현장 사람의 이야기라는 게 전달됩니다. 차량에 회사 로고가 없어야 합니다.

> **표현 주의:** "제가 돌려보낸 사람"이 아니라 **"호주 현장에서는 보통"**
> 으로 말하세요. 본인 회사의 실제 사례를 말하는 순간 문제가 됩니다.
> 업계 일반 규칙으로만 다루면 안전하고, 정보 가치도 똑같습니다.

**첫 3초**

> 화면: 차 안, 사복 또는 로고 없는 티셔츠
> 자막: **"호주 현장에서 이거 하면 그날로 집에 갑니다"**
> 말: "한국에서는 그냥 넘어가는 것들입니다."

**구성 (30~40초)**

| 초 | 내용 | 화면 |
| --- | --- | --- |
| 0-4 | 위 훅 | 차 안 토킹헤드 |
| 4-13 | 1번 `[본인이 아는 일반 규칙]` | 자막 번호 크게 |
| 13-22 | 2번 `[일반 규칙]` | 자막 |
| 22-31 | 3번 `[가장 흔한 것을 마지막에]` | 자막 |
| 31-36 | "악의가 아니라 몰라서 그러는 겁니다" | 토킹헤드 |
| 36-40 | CTA | — |

**CTA:** "저장해두세요. 첫 출근 전날 다시 보시면 됩니다."

저장률이 지금 0.15입니다. 이 한 줄이 그걸 올립니다.

**캡션**

```
호주 현장에서 통하는 규칙들입니다.

한국 현장이면 넘어갈 일인데 여기선 그날로 끝납니다.
악의가 있어서가 아니라 몰라서 그러는 경우가 대부분입니다.

첫 출근 앞두신 분들 저장해두세요.

#호주건설 #안전관리 #호주취업 #시드니 #호주워홀 #건설현장
```

## 찍고 나서 반드시 할 것

올린 지 **48시간 뒤** 인사이트를 열어 기록하세요.

```bash
python3 content-engine/ideas.py --log "White Card 실제 비용" \
  --angle checklist --reach <조회한 사람> --follows <팔로우> --saves <저장>
```

## 미리 알고 계세요

**조회수는 "호주숲"보다 훨씬 낮게 나옵니다.** 3천~1만 사이일 겁니다.
호기심으로 퍼지는 주제가 아니기 때문입니다.

**팔로우와 저장은 더 많이 나올 겁니다.** 그게 목표입니다.
조회수가 낮다고 다시 호기심 콘텐츠로 돌아가면 지난 552개와 같은 결과입니다.

숫자는 **팔로우/1k** 하나만 보세요.
